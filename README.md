# MoodTracker++

Демонстрационное приложение для изучения различных подходов к персистентности во Flutter.

## Описание

MoodTracker++ - это приложение для отслеживания настроения, которое будет использоваться для демонстрации различных библиотек и подходов к сохранению данных:

### Структура веток

| Ветка | Описание | Тестовое покрытие |
|-------|----------|-------------------|
| **00_initial** | Базовая версия без персистентности | 98.7% (379 из 384 строк) |
| **01_shared_prefs** | Добавлена авторизация и настройки через SharedPreferences | 99.2% (628 из 633 строк) |
| **02_sqflite** | *Планируется: сохранение записей настроения в SQLite* | - |
| **03_objectbox** | *Планируется: использование ObjectBox для хранения данных* | - |
| **04_isar** | *Планируется: миграция на Isar Database* | - |
| **05_hive** | *Планируется: использование Hive для локального хранения* | - |

## Функционал

- Запись настроения с эмодзи и цветовой индикацией
- Добавление заметок к записям
- Отметка активностей
- История записей
- Статистика настроений
- Визуализация данных

## Описание веток

### Ветка 00_initial

Базовая версия приложения без персистентности. Все данные хранятся в памяти и теряются при перезапуске.

**Функционал:**
- Запись настроения с эмодзи
- Добавление заметок и активностей
- Отслеживание времени сна
- История записей
- Статистика настроений
- Переключение темы (светлая/темная)

**Используемые пакеты:**
- provider - управление состоянием
- intl - форматирование дат

### Ветка 01_shared_prefs

Добавлена персистентность настроек и авторизация пользователя.

**Новый функционал:**
- Авторизация пользователя (логин/пароль)
- Экран профиля с настройками
- Сохранение настроек:
  - Тема приложения
  - Включение/выключение уведомлений
  - Интервал напоминаний о настроении
  - Счетчик открытий приложения
- Персистентность авторизации между сессиями

**Дополнительные пакеты:**
- shared_preferences - хранение настроек

**Важно:** Записи настроения по-прежнему хранятся только в памяти!
